# clavabit

Telegram-бот активности для чата @clavekchat (python-telegram-bot ≥ 22, SQLite).

## Запуск

```
pip install -r requirements.txt
BOT_TOKEN=... python main.py        # или python bot.py
```

Токен берётся из переменной `BOT_TOKEN` (или `TOKEN`), иначе из файла `token.txt` рядом с ботом.
Токен и база `*.db` в Git не попадают (`.gitignore`). Папку с базой можно задать переменной `DATA_DIR`.

## Структура

| Папка / файл | Что внутри |
|---|---|
| `main.py`, `bot.py` | точки входа, обе вызывают `app.main()` |
| `app.py` | сборка приложения: хендлеры, запуск |
| `scheduler.py` | планировщик: итоги дня, вопрос и викторина, реклама, ежедневные события |
| `config.py` | все настройки и числа экономики |
| `database/` | `db.py` — подключение, таблицы и миграции; `state.py` — хранилище ключ-значение |
| `content/` | тексты справки, статические данные, статья для Telegraph |
| `core/` | утилиты, антиспам, ранги и права (`need`), общие помощники хендлеров |
| `services/` | логика без привязки к Telegram: очки, топы, итоги, викторина, отношения, работа, монеты, картинки, свидетельство, Telegraph |
| `handlers/` | команды и кнопки по темам: профили, мини-игры, дуэли, NFT, модерация, отношения, работа, брак, дома и питомцы, магазин, жалобы, меню; `router.py` разбирает слова-команды |

Слои зависят только «вниз»: `handlers` → `services` → `core` → `database`/`config`. Циклических импортов нет.

## Как добавить команду

1. Напиши функцию в подходящем модуле `handlers/` (права: декоратор `@need("ключ")`).
2. Зарегистрируй её в `app.py` (слэш-команда) и/или в `USER_ALIASES` / `ADMIN_ALIASES` в `handlers/router.py` (команда словами).
3. Новую таблицу или столбец добавь в `database/db.py`.

## Mini App (игры и смены)

Страница лежит в `docs/` (`index.html`, `css/`, `js/`) и публикуется через GitHub Pages. Что внутри:
- смена профессии: ссылка из чата открывает мини-игру своей профессии, результат уходит боту (`/start r_<сессия>_<очки>`);
- хаб `/play`: Монополия против 1–3 ботов, 2048, Сапёр, Змейка и тренировка профессий (без наград).

Подключение:
1. GitHub → Settings → Pages → Source: ветка `main`, папка `/docs`. Адрес будет `https://dombezcdd.github.io/clavabit/`.
2. @BotFather → `/newapp` → выбрать бота → название, описание, картинка 640×360 → URL из пункта 1 → короткое имя `work`
   (если выбрал другое, поменяй `MINI_APP` в `config.py`).
3. Перезапусти бота. Пустое `MINI_APP = ""` отключает кнопку.

Награда: результат присылает клиент, поэтому множитель оплаты ограничен (`MINI_MULT` в `config.py`, максимум ×1.5),
засчитывается одна игра на одно открытое задание, не раньше `MINI_SESSION_MIN` секунд и только владельцу сессии.

## Монополия в чате

Команда `/monopoly` или слово «монополия»: бот присылает лобби с кнопками (присоединиться, добавить бота, начать). Партия на 2–6 игроков
идёт в одном сообщении-картинке: ходы по кнопкам, поле рисует Pillow (`services/monopoly_board.py`, шрифт лежит в `assets/fonts`).
Правила и логика: `services/monopoly.py` (без Telegram, проверяется случайными партиями), кнопки и таймауты: `handlers/monopoly.py`.
Ход ждут `MONO_TURN_TIMEOUT` секунд, дальше бот бросает за игрока; два пропуска подряд = игрок выбывает.
Награды нет, победы идут в рейтинг «топ игр». Остановить: «стоп монополия» (создатель или владелец).
